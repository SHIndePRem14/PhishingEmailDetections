About PhishGuard

PhishGuard is an AI-powered phishing email detection system built as a final-year cybersecurity project. It combines a TF-IDF + Logistic Regression machine learning model with keyword and URL heuristics to classify emails as legitimate or phishing, and stores results for dashboard analytics and Power BI reporting.

PhishGuard never opens, executes, or downloads links/attachments from analyzed emails.
