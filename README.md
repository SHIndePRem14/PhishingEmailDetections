# PhishGuard — AI-Powered Phishing Email Detection System

PhishGuard is a full-stack web application that detects whether an email is **Phishing/Suspicious**
or **Legitimate/Safe** using a Machine Learning model (TF-IDF + Logistic Regression), combined with
keyword and URL heuristics. Built as a final-year Cybersecurity / IT / Computer Engineering project.

## Features

- Secure authentication (login, registration, admin login, role-based access, hashed passwords)
- User dashboard: totals, accuracy, threat percentage, recent history, model info
- Email analysis: sender/receiver/subject/body input, NLP preprocessing, ML prediction
- Detection result page: prediction, confidence, risk level, suspicious keywords, suspicious URLs
- Suspicious keyword detection (18 phishing-indicative phrases) with a keyword risk score
- Suspicious URL detection (HTTP, IP-based hosts, shorteners, odd TLDs, brand mimicry, etc.)
- Detection history with search, filter, sort, and pagination
- Admin dashboard: user management, all detections, model metrics, audit logs
- Power BI–ready MySQL schema for analytics dashboards
- CSRF protection, input validation, SQL-injection-safe ORM queries, XSS-safe templates
- Application logging and custom 400/403/404/500 error pages
- Automated tests (auth, detection heuristics, ML service)

## Technology Stack

**Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript, Font Awesome, Jinja2
**Backend:** Python 3.12, Flask, Flask-SQLAlchemy, Flask-Migrate, Flask-Login, Flask-WTF, Werkzeug, python-dotenv
**Database:** MySQL (via PyMySQL)
**ML:** pandas, NumPy, scikit-learn, joblib, NLTK — TF-IDF + Logistic Regression
**Visualization:** Microsoft Power BI (connects directly to MySQL)

## Architecture

Flask application factory pattern with blueprints: `auth`, `main`, `detection`, `admin`.
ML logic lives in `app/services/` and is loaded once (not retrained per request).

## Requirements

## Setup (Windows)

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure environment variables
copy .env.example .env
# then edit .env with your MySQL credentials

# 4. Create the MySQL database (pick ONE option)
#    Option A: let Flask-Migrate create tables
flask db init
flask db migrate -m "Initial migration"
flask db upgrade

#    Option B: create it manually
mysql -u root -p < database/schema.sql

# 5. Train the ML model (creates ml_models/*.pkl)
python scripts/train_model.py

# 6. Create an admin account
python scripts/create_admin.py

# 7. (Optional) Load demo data
python scripts/seed_data.py

# 8. Run the application
python run.py
```

The app starts at: **http://127.0.0.1:5000**

## Setup (macOS / Linux)

Same as above, but activate the virtual environment with:

```bash
source .venv/bin/activate
```

## Environment Variables (`.env`)

```env
SECRET_KEY=change-this-secret-key

MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DATABASE=phishguard
MYSQL_USER=root
MYSQL_PASSWORD=your_mysql_password
```

Never commit `.env` — only `.env.example` is tracked.

## ML Model Training

`scripts/train_model.py` loads `dataset/phishing_emails.csv` (columns: `text`, `label`), cleans the
text, trains a TF-IDF vectorizer + Logistic Regression model, evaluates accuracy/precision/recall/F1,
and saves the model, vectorizer, and metrics into `ml_models/`. Replace the sample CSV with a larger
real-world dataset for stronger accuracy before a real demonstration.

```bash
python scripts/train_model.py            # uses the bundled sample dataset
python scripts/train_model.py path/to/your_dataset.csv
```

## Power BI Connection

1. Open Power BI Desktop → **Get Data** → **MySQL Database**.
2. Server: `localhost:3306` (or your MYSQL_HOST/PORT), Database: `phishguard`.
3. Import the `email_detections`, `model_metrics`, and `users` tables.
4. Build KPI cards (Total Emails, Phishing %, Avg. Confidence) and charts (Phishing vs Legitimate,
   detection trends over time, risk-level distribution, top suspicious keywords) from `email_detections`.

## Troubleshooting

| Issue | Fix |
|---|---|
| `ModelNotFoundError` on Analyze page | Run `python scripts/train_model.py` first |
| MySQL connection refused | Confirm MySQL is running and `.env` credentials are correct |
| `flask db` command not found | Ensure the virtual environment is activated and `FLASK_APP` isn't required — this project uses `run.py` directly; run `flask db init` from the project root |
| CSRF token errors | Make sure cookies are enabled and you're not mixing http/https origins |
| 403 on `/admin` | The logged-in account isn't an admin — run `scripts/create_admin.py` |

## Security Notes

Passwords are hashed with Werkzeug's `generate_password_hash`. CSRF protection is enabled globally via
Flask-WTF. All database access goes through SQLAlchemy's ORM (parameterized queries). PhishGuard never
opens, executes, or downloads links/attachments from analyzed emails — it only inspects the text.
